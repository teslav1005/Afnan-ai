# صفحة محمود الشخصية

هذه نسخة ثابتة تعمل بـ HTML وCSS وJavaScript فقط، ومناسبة للرفع على GitHub Pages. ارفع محتويات هذا المجلد إلى المستودع، ثم فعّل Pages من Settings > Pages واختر الفرع والمجلد الجذر. بعد ربط الدومين `afnanai.com` حدّث إعدادات DNS لدى مزود الدومين، ثم ارفع `sitemap.xml` إلى Google Search Console.

الملفات الأساسية هي `index.html` و`style.css` و`script.js` ومجلد `images` الذي يحتوي الصور الشخصية المنظفة من بيانات EXIF.
